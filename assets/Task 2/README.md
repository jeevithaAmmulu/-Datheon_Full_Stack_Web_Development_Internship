### Task 2 — Dynamic Task Manager & Productivity Tracker (CRUD): task-02-task-manager/
 
**Live Demo:** https://datheon-task-2-git-main-jeevithaammulu.vercel.app/
 
A responsive task management application built using HTML5, CSS3, and vanilla JavaScript. Features include Create, Read, Update, and Delete (CRUD) operations, task categorization, due date management, completion tracking, filtering options, localStorage persistence, responsive design, and an intuitive user interface for efficient productivity management.
